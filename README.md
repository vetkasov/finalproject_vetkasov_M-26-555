# ValutaTrade Hub

Консольный симулятор торговли валютами. Можно зарегистрироваться, собрать
виртуальный портфель и посмотреть курсы фиатных валют и криптовалют к USD
или другой поддерживаемой валюте.

## Установка и запуск

Нужны Git, Python 3.12 или новее и [uv](https://docs.astral.sh/uv/).

~~~sh
git clone https://github.com/vetkasov/finalproject_vetkasov_M-26-555.git
cd finalproject_vetkasov_M-26-555
uv sync --locked
uv run project
~~~

Команда `make install` выполняет ту же установку. Для запуска приложения
ключи API не нужны. Чтобы проверить работу без обращения к API, после входа
выполните `buy --currency USD --amount 1` и `show-portfolio`.

Равнозначный запуск из исходников — `python main.py` в окружении проекта.
Команда `make lint` проверяет стиль и форматирование через Ruff,
`make build` собирает архив исходников и wheel. Для установки wheel
в отдельное окружение проекта:

~~~sh
make package-install
.tools/bin/project
~~~

## Источники курсов

Криптовалюты загружаются из CoinGecko. Для EUR, GBP и RUB зарегистрируйтесь
в [ExchangeRate-API](https://www.exchangerate-api.com/) и задайте полученный
ключ перед запуском:

~~~sh
export EXCHANGERATE_API_KEY="ваш-ключ"
uv run project
~~~

Если CoinGecko требует ключ, задайте `COINGECKO_API_KEY` с ключом тарифа Demo.
Если один источник недоступен, обновятся курсы второго. Старые значения
сохранят свои даты. Если оба источника недоступны, кеш не перезаписывается.

## Пример работы

Команды ниже вводятся в приглашении `>` внутри приложения.
Для примера подойдёт обновление только криптовалютных курсов:

~~~text
update-rates --source coingecko
register --username alice --password demo-pass
login --username alice --password demo-pass
buy --currency BTC --amount 0.05
sell --currency BTC --amount 0.01
show-portfolio --base USD
get-rate --from USD --to BTC
show-rates --currency BTC
show-rates --top 2
exit
~~~

При наличии фиатных курсов попробуйте `show-rates --base EUR` и
`show-portfolio --base EUR`. `update-rates` без аргументов опрашивает оба
источника. `help` показывает команды, а `help buy` — параметры покупки.
Для портфеля в BTC или другой криптовалюте выводится больше знаков
после запятой, чтобы небольшие суммы оставались видны.

При регистрации создаётся пустой портфель. Пароль хранится как хеш
PBKDF2-HMAC-SHA256 с индивидуальной солью. Успешный `login` заменяет текущую
сессию, сессия заканчивается при выходе из программы. Покупка увеличивает
баланс выбранной валюты, продажа уменьшает его. Доллары используются для
оценки сделки, поэтому отдельный USD-кошелёк для расчётов не требуется.

## Кеш, данные и логи

- `data/users.json` и `data/portfolios.json` хранят пользователей и кошельки.
- `data/rates.json` хранит последние курсы, время обновления каждой пары
  и время обновления снимка. `data/exchange_rates.json` хранит историю измерений.
- `get-rate` запрашивает обновление, когда нужный курс отсутствует или старше
  пяти минут. Для кросс-курса проверяется свежесть обеих пар к USD.
  `show-rates`, `show-portfolio` и оценка сделок используют локальный кеш.
- `logs/actions.log` содержит результаты покупок и продаж,
  `logs/parser.log` — результаты запросов и причины сбоев. Логи ротируются.
  Вывод парсера дублируется в консоль во время `update-rates`.

Настройки находятся в `[tool.valutatrade]` в `pyproject.toml`. Для работы
с отдельными данными и логами можно задать `VALUTATRADE_DATA_DIR` и
`VALUTATRADE_LOG_DIR` перед запуском. Пути по умолчанию считаются от рабочей
папки. Для периодического обновления запустите в этой же папке
`uv run python -m valutatrade_hub.parser_service.scheduler`. Интервал по
умолчанию — один час, он задаётся в `ParserConfig`.

## Структура

- `main.py` — вход в приложение.
- `valutatrade_hub/core/` — модели, реестр валют и сценарии работы с портфелем.
- `valutatrade_hub/infra/` — настройки и JSON-хранилище.
- `valutatrade_hub/parser_service/` — клиенты API, обновление и история курсов.
- `valutatrade_hub/cli/` — команды, форматирование вывода и текущая сессия.

[Смотреть запись работы терминала на asciinema.org](https://asciinema.org/a/yugUrK1I9ksbp0je).
В записи показаны покупка и продажа, оценка портфеля, запрос курса,
обновление и фильтр кеша, а также сообщения об ошибках.
